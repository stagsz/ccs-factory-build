# Factory backlog

`/factory next` takes the first unchecked item, creates a job and marks it `[~]` with the job id.
When the job ends, `board.mjs stage` closes the line: `[x]` merged, `[!]` failed.
Format: `- [ ] Short title :: optional longer request for the spec writer`

- [x] Decide merge failures by MERGE_HEAD, not git's message :: SKILL.md step 5 (`local` merge) tells a conflict from a refused merge by reading git's output.
